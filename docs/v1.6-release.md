# v1.6 发布报告

## 发布结论

v1.6 已完成并具备本地模型服务与长会话运行能力。版本目标从“完成模型部署”扩展到“本地模型可以被 Agent 稳定调用，并且长会话不会无限膨胀”。

本版本不重新启动 SFT。v1.3 的 E9 退出门禁已经确认微调目标闭环，后续质量问题进入检索、证据和运行时工程治理。

## 已交付能力

- 固定 Qwen3-4B + E6.1 LoRA 的模型身份、输入 manifest 和 SHA-256 校验。
- 完成 adapter BF16、merged BF16、GGUF F16、GGUF `Q4_K_M` 四类部署 profile。
- 支持 Windows 原生 Transformers 与 llama.cpp 部署链路。
- 增加本地模型 HTTP 服务、OpenAI-compatible API、请求队列和服务指标。
- 增加 gateway 重试、fallback、熔断和 half-open 恢复机制。
- 将本地模型路由状态暴露到 UI，支持查看当前服务状态。
- 增加会话摘要、上下文预算、持久化摘要版本和恢复后的继续压缩。
- 保留完整会话与工具消息边界，避免压缩破坏研究证据链。
